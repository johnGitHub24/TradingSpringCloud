Feign 聚合 — Dashboard

  • GET /api/v1/dashboard 一次取 trust + orders。
  • DashboardService 呼叫兩個 Feign Client。
  • 組裝 DashboardResponse（common DTO）。
  • 無 Eureka／Config（固定 URL 教學）。
sequenceDiagram participant C as Client participant G as Gateway :8080 participant L as loop :8081 participant O as order :8082 C->>G: GET /dashboard G->>L: Feign /trust G->>O: Feign /orders G-->>C: DashboardResponse

對照 TradingMicroService 的 lb:// 服務發現。

Gateway MVC — 路徑代理

  • /proxy/loop/** → loop /api/v1/**。
  • /proxy/orders/** → order /api/v1/orders/**。
  • GatewayRouteConfig 改寫路徑。
  • HTTP/1.1 client 固定指向 ServiceUrlsProperties。
flowchart LR C[Client] --> G[Gateway :8080] G -->|/proxy/loop/**| L[loop :8081] G -->|/proxy/orders/**| O[order :8082]

啟動：scripts/start-all.ps1 三模組。

服務 — loop / order

  • loop-service：信任分查詢／累加（記憶體）。
  • order-service：訂單查詢 Map（記憶體）。
  • 無 DB／Kafka／Redis（刻意精簡）。
  • ProblemDetail 統一 404 等錯誤。

詳見 docs/功能流程說明.md。
