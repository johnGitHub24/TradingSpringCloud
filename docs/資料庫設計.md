# 資料庫設計 — TradingSpringCloud

> 衝突以 [TradingSpringCloud 規格書.md](../TradingSpringCloud%20規格書.md) 第 3 章為準。  
> 規範：EngineeringOS `knowledge/database-design.md`  
> **本專案無資料庫**；order／loop 以記憶體模擬。

## 1. 存取鏈

```text
Gateway（代理／Feign）→ loop-service / order-service
  → 記憶體計數或 ConcurrentHashMap
```

Gateway 不持有業務狀態。

## 2. 記憶體「資料集」

| 服務 | 結構 | 種子／行為 |
|------|------|------------|
| `loop-service` | 信任分計數 | `GET/POST /api/v1/trust*` |
| `order-service` | 訂單 Map | 種子：`1001` BTCUSDT／FILLED、`1002` ETHUSDT／NEW |

## 3. Entity 對照

無 JPA Entity。共用 DTO：`TrustResponse`、`OrderSummaryResponse`、`DashboardResponse`（`common`）。

## 4. 環境

| 環境 | 儲存 |
|------|------|
| 本機／測試 | JVM 記憶體（WireMock 僅測 Gateway 下游） |

## 5. 驗證

不適用 SQL schema 檢查。以單元／整合測試確認種子訂單與信任分行為。
