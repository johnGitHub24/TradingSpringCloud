# 架構學習導引 — Trading Spring Cloud

## Spring Cloud 概念對照

| 概念 | 本專案 | 一句話 |
|------|--------|--------|
| 微服務拆分 | loop + order | 各服務獨立 port、獨立 bootRun |
| Gateway MVC | `GatewayRouteConfig` | 統一入口轉發 `/proxy/**` |
| OpenFeign | `*ServiceClient` | 宣告式 HTTP 呼叫下游 |
| 聚合 API | `DashboardService` | 一個 API 組合多服務資料 |
| 共用契約 | `common` 模組 | DTO 跨服務共用 |

## 與 APIGatewayMQ 差異

| 項目 | TradingSpringCloud | APIGatewayMQ |
|------|-------------------|--------------|
| Gateway | Spring Cloud Gateway MVC | WebFlux + 限流 |
| 通訊 | 同步 HTTP | Kafka 非同步 |
| 複雜度 | 入門 | 高併發實戰 |

## 五專案路線

① TransactionClosedStateMachine → ② MVP → **③ 本專案** → ④ APIGatewayMQ → ⑤ TradingKubernetes
