# 驗證設計 — TradingSpringCloud

> 衝突以 [TradingSpringCloud 規格書.md](../TradingSpringCloud%20規格書.md)、[API規格書.md](../API規格書.md) 為準。  
> 規範：EngineeringOS `knowledge/validation-design.md`  
> 本專案**無 JWT／角色授權**。

## 1. 分層

| 層 | 機制 | 典型結果 |
|----|------|----------|
| L1 傳輸 | Gateway MVC 代理／Feign | 下游不可用 → 5xx（框架預設） |
| L2 格式 | 路徑參數／JSON | 依 Spring MVC |
| L3 業務 | `OrderQueryService` 查無訂單 | 404 `ORDER_NOT_FOUND` ProblemDetail |
| L4 資料 | 記憶體 Map | 同 L3 |

## 2. 端點（公開）

| 端點 | 模組 | 說明 |
|------|------|------|
| `GET /api/v1/dashboard` | gateway | Feign 聚合 |
| `GET /api/v1/gateway/routes` | gateway | 路由檢視 |
| `GET /proxy/loop/{segment}` | gateway | 代理 loop |
| `GET /proxy/orders/{segment}` | gateway | 代理 order |
| `GET /api/v1/trust`、`POST /api/v1/trust/increment` | loop | 信任分 |
| `GET /api/v1/health/ping` | loop | ping |
| `GET /api/v1/orders`、`GET /api/v1/orders/{id}` | order | 列表／單筆 |

## 3. 錯誤碼

| 情境 | HTTP | errorCode／形式 |
|------|------|-----------------|
| 訂單不存在 | 404 | `ORDER_NOT_FOUND`（`ProblemDetail`） |
| 下游失敗 | 500 | 框架預設 |

## 4. 對照程式

| 角色 | 類別 |
|------|------|
| 聚合 | `DashboardController`／`DashboardService` |
| 代理 | `GatewayRouteConfig` |
| Feign | `LoopServiceClient`／`OrderServiceClient` |
| 404 | `OrderNotFoundException` + `GlobalExceptionHandler` |
