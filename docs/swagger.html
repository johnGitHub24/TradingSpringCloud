啟動與位址

啟動依序 .\gradlew.bat :loop-service:bootRun、:order-service:bootRun、:gateway:bootRun（各開一個終端）
gateway:8080 · JSON /v3/api-docs
loop-service:8081 · JSON /v3/api-docs
order-service:8082 · JSON /v3/api-docs
驗證.\scripts\check.ps1（= gradlew check）

API 分組（實際 Controller）

  • Gateway 聚合（Feign）：GET /api/v1/dashboard（聚合 loop + order）、GET /api/v1/gateway/routes
  • Gateway 代理：/proxy/loop/{segment} → loop /api/v1/{segment}；/proxy/orders/{segment} → order /api/v1/orders/{segment}
  • loop-service：GET /api/v1/trust、POST /api/v1/trust/increment、GET /api/v1/health/ping
  • order-service：GET /api/v1/orders、GET /api/v1/orders/{orderId}

認證與範例流程

  • 無認證（無 Spring Security／JWT）。
  • 教學重點：同一下游，走 代理（/proxy/*，Gateway 只轉發）與走 聚合（/dashboard，Gateway 用 Feign 合併多服務）比較。
  • 範例：GET :8080/api/v1/dashboard → 觀察聚合結果；再 GET :8080/proxy/loop/trust 對照代理路徑。

右上下拉可切換 Gateway／Loop／Order 三份規格（各自載入該服務 /v3/api-docs，需先啟動對應服務）。 若以 file:// 直接開啟本頁而無法載入，請改用各服務的 /swagger-ui.html，或在 docs 目錄啟一個靜態伺服器。
