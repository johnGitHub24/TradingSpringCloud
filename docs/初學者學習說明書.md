# 初學者學習說明書 — Trading Spring Cloud

> **前提：** 已完成 TransactionClosedStateMachine（Spring Boot 單體）。  
> **目標：** 3 天理解 Gateway MVC + OpenFeign。

## Day 1 — 多服務啟動

1. `.\scripts\start-all.ps1`
2. 分別開 Swagger：8081 / 8082 / 8080
3. 讀 `loop-service` 的 `TrustController`、`order-service` 的 `OrderQueryController`

## Day 2 — Gateway MVC 代理

1. 讀 `gateway/.../GatewayRouteConfig.java`
2. 瀏覽器打 `http://localhost:8080/proxy/loop/trust`
3. 對照 SpringBootDemo 的 `GatewayConfig.java`

## Day 3 — OpenFeign 聚合

1. 讀 `LoopServiceClient`、`OrderServiceClient`、`DashboardService`
2. 打 `GET /api/v1/dashboard`
3. 跑 `.\gradlew.bat test`，看 `DashboardIntegrationTest`

## 常見問題

| 問題 | 解法 |
|------|------|
| Dashboard 500 | 確認 8081、8082 已啟動 |
| Connection refused | 檢查 `application.yml` 的 `trading.services.*-url` |
| 測試失敗 | gateway 測試用 WireMock，不需真服務 |
